# Changelog

## 1.0.0 - 2026-09-05

- Initial public release.
- Display courses from one or more selected categories.
- Optional recursive inclusion of sub-categories.
- Plugin-provided responsive card layout with course image, course name, and short summary.
- Optional Moodle/theme-controlled course listing.
- Dedicated 16:9 image wrapper with centered cropping for plugin-rendered course cards.
- Optional custom block title.
- Configurable courses per page (1-36, default 12).
- Independent pagination for multiple block instances on the same page.
